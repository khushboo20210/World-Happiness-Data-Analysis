# World Happiness Data Analysis and Visualization

## Project Description

This project analyzes the World Happiness dataset using Python and data visualization techniques. The main objective is to understand the happiness levels of different countries and identify the factors associated with happiness.

## Dataset

The dataset used in this project is the **World Happiness dataset** obtained from Kaggle.

The project uses the **2019 World Happiness dataset**.

The dataset contains information about:

* Happiness Score
* GDP per Capita
* Social Support
* Healthy Life Expectancy
* Freedom to Make Life Choices
* Generosity
* Perceptions of Corruption

## Technologies and Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* Kaggle
* GitHub

## Data Analysis

The project includes:

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Outlier Detection
5. Data Visualization
6. Correlation Analysis
7. Insights and Findings

## Visualizations

The following graphs were created:

* Distribution of Happiness Score
* Top 10 Happiest Countries
* GDP per Capita vs Happiness Score
* Social Support vs Happiness Score
* Healthy Life Expectancy vs Happiness Score
* Generosity of Top 10 Happiest Countries
* Correlation Heatmap

## Key Findings

* GDP per capita has a strong positive relationship with Happiness Score.
* Healthy life expectancy has a strong positive relationship with Happiness Score.
* Social support has a strong positive relationship with Happiness Score.
* Freedom to make life choices has a moderate positive relationship with Happiness Score.
* Generosity has a very weak relationship with Happiness Score.

## Conclusion

The analysis shows that economic conditions, health, and social support are important factors associated with happiness among countries in the 2019 dataset.

This project demonstrates the use of Python and data visualization techniques for real-world data analysis.
